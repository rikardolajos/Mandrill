Detailed Description

Material parameters on glTF's metallic-roughness basis, which is what both loaders convert into. The factors multiply their corresponding texture where one is present, as in glTF.

The defaults are glTF's own, so a material only has to set what the file actually authored.

Note that the base color and emissive textures still load into a UNORM format, so what a shader samples from them is sRGB encoded rather than the linear value this basis calls for. Correcting that means encoding on output as well, since the swapchain is UNORM too.

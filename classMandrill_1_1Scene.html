◆ createDescriptors()

void Scene::createDescriptors ( ptr< Camera >  pCamera)

Attach the scene's resources to the shaders its nodes are rendered with.

Which shaders those are is taken from the pipelines the nodes carry, so every node has to have its pipeline set before this is called. Nodes may well use different pipelines, and those pipelines may use different shaders; each distinct shader gets the resources attached to it and a set of materials prepared for it. Swapping a node to another pipeline afterwards is fine as long as it uses a shader that was present here, which is the case when the pipelines only differ in state.

Resources are matched to a shader by the name they are declared with, not by set and binding number, so the shader decides where they end up. Declare them like this, in any set and at any binding:

Resources the scene expects to find in the shader
Name in shader Contents Declared as
camera Camera matrices (struct CameraMatrices) uniform block named *Dynamic
mesh Node model matrix (mat4) uniform block named *Dynamic
materialParams Material parameters (struct MaterialParams) uniform block
diffuseTexture Material diffuse texture sampler2D
specularTexture Material specular texture sampler2D
ambientTexture Material ambient texture sampler2D
emissionTexture Material emission texture sampler2D
normalTexture Material normal texture sampler2D
environmentMap Environment map texture sampler2D, optional

The camera and the node transforms live in one buffer each that is rebound with a dynamic offset, which is why their blocks have to be named with a *Dynamic suffix. They are bound with different offsets, so they have to be in separate sets.

A whole material is bound in one go for every mesh, so the material resources all have to share one set, declared in the order they are listed above. That set is found from diffuseTexture.

Only the environment map is optional. A shader that does not declare it simply renders without one.

Parameters
pCameraCamera whose matrices the scene is rendered with

void Scene::createRayTracingDescriptors ( ptr< Shader >  pShader,
ptr< Camera >  pCamera,
const ptr< AccelerationStructure >  pAccelerationStructure

Attach the scene's resources to a ray-tracing shader.

As with createDescriptors(), resources are matched by the name they are declared with rather than by set and binding number:

Resources the scene expects to find in the shader
Name in shader Contents Declared as
camera Camera matrices (struct CameraMatrices) uniform block named *Dynamic
scene Acceleration structure accelerationStructureEXT
vertexBuffer Global vertex buffer readonly buffer block
indexBuffer Global index buffer readonly buffer block
instanceDataBuffer Vertex and index offsets per instance readonly buffer block
materialBuffer Global material buffer readonly buffer block
textures Global texture array sampler2D array
environmentMap Environment map texture sampler2D, optional

A buffer block needs an instance name for the scene to find it, since a block declared without one is only reachable through its block type name. The texture array has to be sized by a specialization constant that is set to Scene::getTextureCount().

Nothing varies per dispatch the way a node transform varies per draw, so the scene has no bind function of its own here. Bind everything, the scene's resources and the application's alike, with a single call to Shader::bindResources(cmd, bindPoint) before tracing.

Parameters
pShaderShader the scene is traced with, used to attach the resources
pCameraCamera whose matrices the scene is traced with
pAccelerationStructureAcceleration structure to bind

◆ syncToDevice()

void Scene::syncToDevice ( )

Synchronize buffers to device.

Upload all buffers from host to device. This function should be called after updates have been made to the scene.

Node transforms and material parameters are kept host coherent and can be changed without requiring a new sync.
